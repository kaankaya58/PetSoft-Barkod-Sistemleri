# PetSoft Barkod Sistemleri Güncelleme Kanalı

Bu depo PetSoft Barkod Sistemleri masaüstü uygulamasının otomatik güncelleme dosyalarını barındırır.

- `manifest.json`: Uygulamanın kontrol ettiği güncel sürüm bilgisi
- `updates/`: İndirilebilir güncelleme paketleri

> Kullanıcı veritabanı ve mağaza verileri bu depoda tutulmaz.
